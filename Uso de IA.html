¿Cómo utilicé la IA en mi aplicación web?

La IA que se utilizó para asistirme en este proyecto fue Copilot. Esta IA se utilizó para

ayudarme a hacer el código para crear cuentas en mi aplicación web. Por esta también fue que

encontré que se podía guardar esta información en el local storage. El cual es utilizado para

guardar las tablas por ID de usuario y las filas por tablas. Me ayudó a mejorar la base de datos

inicial para guardarla de forma más eficaz y organizada. La cual me llevó a hacer el cambio de

que cada usuario genere su propio ID automáticamente cada uno siendo distinto. Copilot

también creó el diseño inicial de la página de iniciar sección de la cual me dejé llevar para

realizar la página en donde el usuario crea una cuenta nueva. La página principal que es donde

se realizan las tablas con el inventario, me ayudó a poder crearla para que funcione

correctamente. Fue de asistencia en la creación de las funciones principales de esta parte ya

que se necesitó utilizar java script para hacer que funcionara cómo se esperaba. Una vez se

codificó todo, se le preguntó a Copilot que función tenía cada línea del código de java script y

parte del código de CSS. Las cuales fueron explicadas una a una en mis propias palabras según

Copilot me explicaba en donde tenía dudas. Gracias a todo lo que fui preguntando según

realizaba el proyecto, fui conociendo mejor cómo funcionaba java script. Lo cual me llamó la

atención ya que encontré varias similitudes entre este lenguaje de programación y C++ lo cual

me ayudó a entender varias partes del código. Me ayudó a descubrir un lenguaje nuevo el cual

pienso aprender en el futuro ya que gracias a este proyecto pude ver lo que se puede hacer con

java script. Por esta razón me dio curiosidad y decidí buscar alternativas a java script como

Access o C++ los cuales tenía mayor conocimiento, pero terminé descubriendo que no sería

posible. Ya fuese por necesidad de un servidor o por otras complicaciones que según le

preguntaba a Copilot haría mi proyecto muy complicado a comparación de utilizar HTML, CSS y

java script. Que fue la decisión correcta ya que conocía de HTML y un poco de CSS así que

decidí usar estos dos y el lenguaje del cual conocía poco java script.
